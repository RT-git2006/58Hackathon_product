# 激面白字幕メーカー

58ハッカソン2026（テーマ「インクルーシブ」）参加プロダクト。
マイクの声（音量・ピッチ・話速）とカメラで捉えた体の動きから感情を推定し、誇張した字幕をプロジェクターに投影する。
要件の詳細は [CLAUDE.md](CLAUDE.md) を参照。

## 起動方法

ビルド不要。ローカルサーバーで配信して Chrome で開く（マイク許可のため `localhost` 推奨）。

```sh
python -m http.server 8000
# → Chrome で http://localhost:8000 を開き「はじめる」を押す
```

- 音声認識（Web Speech API）は Chrome ではインターネット接続が必要。
- 体の動き検出（MediaPipe Tasks Vision）は CDN からモデルと wasm を読み込むため、初回起動時もネット接続が必要。カメラが無い/読み込めない場合は声だけで動作する。
- 字幕フォント（Dela Gothic One）は Google Fonts から読み込む。オフライン時は代替フォントで動作する。

## 操作

| キー | 動作 |
| --- | --- |
| `F` / `F11` | フルスクリーン切替 |
| `D` | 解析値（音量・ピッチ・話速・強さ・感情）の表示 |
| `Enter` | テキスト手入力（音声認識が使えない時の代替。`!` の数で強さが上がる） |
| `C` | 字幕をクリア |
| `V` | カメラ映像（骨格）プレビューの表示切替 |

## 構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面の骨組み（キャンバス・起動画面・HUD） |
| `style.css` | 起動画面・HUD・入力欄のスタイル |
| `script.js` | 音声認識 / 音声解析 / 動き検出 / 感情推定 / 字幕アニメーション / メインループ |

### script.js の処理の流れ

1. **音声認識**: `webkitSpeechRecognition`（`ja-JP`, continuous, interim）。途中結果は「発話中の字幕」として表示し、確定したら固定する。止まったら自動再開。
2. **音声解析**: `AnalyserNode` の波形から RMS → dB → 0..1 の音量。自己相関でピッチを推定し、話者の平常時ピッチとの比を「興奮度」とする。話速は発話中の文字数 / 経過時間。
3. **動き検出**: MediaPipe Pose Landmarker（lite モデル, VIDEO モード）で鼻・肩・肘・手首を追跡。肩幅で正規化して「動きの速さ」「両手の広がり」「手を挙げる」「顔を覆う」を 0..1 で出す。
4. **感情推定（声+動き）**: キーワード辞書（`KEYWORDS`）＋声と体の特徴（`prosodyScores`）で 喜び / 驚き / 恐怖 / 怒り / 平常 を選ぶ（例: 両手を挙げる→喜び、顔を覆う→恐怖）。強さは `computeIntensity` で声と動きを 1 つのスコアに統合（声が主で、動きは増幅役）。
5. **字幕アニメーション**: 強さで文字サイズを決定。発話中は今の声に追従して膨らむ。1 文字ずつ弾むようにポップインし、感情ごとに 震え / 跳ね / 波打ち / 脈打ち を付ける。怖い単語はグリッチ付きで激しく震える。大声で確定すると画面揺れ・フラッシュ・衝撃波。

### 調整ポイント

- 反応の感度: `CONFIG.dbFloor` / `CONFIG.dbCeil`（会場のマイクに合わせて `D` キーの dB 値を見ながら調整）
- 文字の最大サイズ: `CONFIG.maxFontRatio`
- キーワード: `KEYWORDS`
- 声と動きの混ぜ方: `computeIntensity` / `prosodyScores`
- 動きの感度: `updateBody` 内の `/ 4`（肩幅/秒の何倍で最大とするか）
