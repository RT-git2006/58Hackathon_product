# 激面白字幕メーカー

58ハッカソン2026（テーマ「インクルーシブ」）参加プロダクト。
マイクの声（音量・ピッチ・話速）とカメラで捉えた体の動きから感情を推定し、誇張した字幕をプロジェクターに投影する。
要件の詳細は [CLAUDE.md](CLAUDE.md) を参照。

## 起動方法

ビルド不要。ローカルサーバーで配信して Chrome で開く（マイク許可のため `localhost` 推奨）。

```sh
python -m http.server 8000
# → Chrome で http://localhost:8000 を開き「はじめる」を押す
```

- 音声認識（Web Speech API）は Chrome ではインターネット接続が必要。
- 体の動き検出（MediaPipe Tasks Vision）は CDN からモデルと wasm を読み込むため、初回起動時もネット接続が必要。カメラが無い/読み込めない場合は声だけで動作する。
- 字幕フォント（Dela Gothic One ほか約 20 種の日本語フォント）は Google Fonts から読み込む。オフライン時は代替フォントで動作する。

## 操作

| キー | 動作 |
| --- | --- |
| `F` / `F11` | フルスクリーン切替 |
| `D` | 解析値（音量・ピッチ・話速・強さ・感情、単語ごとのカテゴリ/フォント）の表示 |
| `Enter` | テキスト手入力（音声認識が使えない時の代替。`!` の数で強さが上がる） |
| `C` | 字幕をクリア |
| `V` | カメラ映像（骨格）プレビューの表示切替 |

## 構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面の骨組み（キャンバス・起動画面・HUD） |
| `style.css` | 起動画面・HUD・入力欄のスタイル |
| `lexicon.js` | 語彙辞書（単語・漢字 → カテゴリ）と、カテゴリごとのフォント・配色・テロップ装飾 |
| `script.js` | 音声認識 / 音声解析 / 動き検出 / 感情推定 / 字幕レイアウト・アニメーション / 吹き出し / メインループ |

### script.js の処理の流れ

1. **音声認識**: `webkitSpeechRecognition`（`ja-JP`, continuous, interim）。途中結果は「発話中の字幕」として表示し、確定したら固定する。止まったら自動再開。
2. **音声解析**: `AnalyserNode` の波形から RMS → dB → 0..1 の音量。自己相関でピッチを推定し、話者の平常時ピッチとの比を「興奮度」とする。話速は発話中の文字数 / 経過時間。
3. **動き検出**: MediaPipe Pose Landmarker（lite モデル, VIDEO モード）で鼻・肩・肘・手首を追跡。肩幅で正規化して「動きの速さ」「両手の広がり」「手を挙げる」「顔を覆う」を 0..1 で出す。
4. **単語分割とカテゴリ推定**: ブラウザ内蔵の辞書 `Intl.Segmenter` で単語に分け、助詞・送り仮名を前の単語にくっつけて文節単位にする。各単語を `lexicon.js` の単語辞書と**漢字 1 文字ごとの意味**（例: 霊→恐怖、炎→パワー、桜→自然）で 恐怖 / 驚き / 喜び / 怒り / 悲しみ / 好き / パワー / ファンタジー / 食べ物 / 自然 / デジタル / おもしろ / 擬音 / カタカナ語 に分類する。辞書に無い単語でも漢字から推定できる。
5. **感情推定（声+動き）**: 単語のカテゴリ＋声と体の特徴（`prosodyScores`）で 喜び / 驚き / 恐怖 / 怒り / 悲しみ / 平常 を選ぶ（例: 両手を挙げる→喜び、顔を覆う→恐怖）。強さは `computeIntensity` で声と動きを 1 つのスコアに統合（声が主で、動きは増幅役）。
6. **字幕レイアウト（リリックビデオ風）**: 単語を行（または縦書きの列）に詰め、組み方を 10 通り試して**画面いっぱいに最も大きく**表示できるものを選ぶ。字幕ごとに 横書き / 縦書き、単語だけ縦書き、吹き出しの有無 をランダムに決める。声が大きかった単語・内容のある単語ほど大きい。
7. **アニメーション**: 単語ごとに 叩きつけ / 落下バウンド / スライド / 回転 / ズーム / 浮上 / 文字が集まる のいずれかで登場し、その後もふわふわ動き続ける。発話中は声に合わせて脈打つ。感情ごとに 震え / 跳ね / 波打ち / 脈打ち / 沈み を付け、怖い単語はグリッチ付きで激しく震える。カメラ（画面全体）は常にゆっくりズーム・回転し、単語が出るたびにドンと寄る。前の字幕は吹き飛ぶように拡大して背景に薄く残る。
8. **見た目**: 単語のカテゴリでフォント・配色を選び、テレビのテロップ風に 影＋黒フチ＋白フチ＋グラデーション 等で描く。吹き出しは感情で輪郭が変わる（平常=角丸、驚き=ウニフラッシュ、怒り=ギザギザ、喜び=もこもこ、恐怖=波打つ、悲しみ=しずく）。驚き・怒り・大声では集中線、確定時には画面揺れ・フラッシュ・衝撃波・紙吹雪。

### 調整ポイント

- 反応の感度: `CONFIG.dbFloor` / `CONFIG.dbCeil`（会場のマイクに合わせて `D` キーの dB 値を見ながら調整）
- 文字の最大サイズ: `CONFIG.maxWordRatio`
- 縦書き・吹き出しの出やすさ: `CONFIG.columnsChance` / `CONFIG.verticalWordChance` / `CONFIG.bubbleChance`
- 語彙・フォント・配色: `lexicon.js` の `WORDS` / `KANJI` / `CATEGORIES`
- 声と動きの混ぜ方: `computeIntensity` / `prosodyScores`
- 動きの感度: `updateBody` 内の `/ 4`（肩幅/秒の何倍で最大とするか）
