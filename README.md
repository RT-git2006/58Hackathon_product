# 激面白字幕メーカー

58ハッカソン2026（テーマ「インクルーシブ」）参加プロダクト。
小学生など、話を集中して聞き続けたり耳だけで理解したりするのが難しい人が、話の内容と気持ちを目で見て直感的につかめるようにする。
マイクの声（音量・ピッチ・話速）とカメラで捉えた表情（笑顔・しかめ面・真顔 など）から感情を推定し、話を動く文字・色・絵文字に変えてプロジェクターに投影する。
要件の詳細は [CLAUDE.md](CLAUDE.md) を参照。

## 起動方法

ビルド不要。ローカルサーバーで配信して Chrome で開く（マイク許可のため `localhost` 推奨）。

```sh
python -m http.server 8000
# → Chrome で http://localhost:8000 を開き「はじめる」を押す
```

- 音声認識（Web Speech API）は Chrome ではインターネット接続が必要。
- 表情の認識（MediaPipe Tasks Vision の Face Landmarker）は CDN からモデルと wasm を読み込むため、初回起動時もネット接続が必要。カメラが無い/読み込めない場合は声だけで動作する。
- 字幕フォント（Dela Gothic One ほか約 20 種の日本語フォント）は Google Fonts から読み込む。オフライン時は代替フォントで動作する。

## 操作

| キー | 動作 |
| --- | --- |
| `F` / `F11` | フルスクリーン切替 |
| `D` | 解析値（音量・ピッチ・話速・強さ・感情、単語ごとのカテゴリ/フォント）の表示 |
| `Enter` | テキスト手入力（音声認識が使えない時の代替。`!` の数で強さが上がる） |
| `C` | 字幕をクリア |
| `V` | カメラ映像（顔の輪郭と今の表情）プレビューの表示切替 |
| `T` | 背景の要約・話題（絵文字）の表示切替 |

## 構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面の骨組み（キャンバス・起動画面・HUD） |
| `style.css` | 起動画面・HUD・入力欄のスタイル |
| `emoji-ja.js` | 日本語の単語 → 絵文字（約 4000 語）と、絵文字 → カテゴリの対応表。`tools/build-emoji-ja.js` で Unicode CLDR / emoji-test.txt から自動生成 |
| `lexicon.js` | 語彙辞書（単語・漢字 → カテゴリ）と、カテゴリごとのフォント・配色・テロップ装飾 |
| `script.js` | 音声認識 / 音声解析 / 表情の認識 / 感情推定 / 字幕レイアウト・アニメーション / 吹き出し / メインループ |

### script.js の処理の流れ

1. **音声認識**: `webkitSpeechRecognition`（`ja-JP`, continuous, interim）。途中結果は「発話中の字幕」として表示し、確定したら固定する。止まったら自動再開。
2. **音声解析**: `AnalyserNode` の波形から RMS → dB → 0..1 の音量。自己相関でピッチを推定し、話者の平常時ピッチとの比を「興奮度」とする。話速は発話中の文字数 / 経過時間。
3. **表情の認識**: MediaPipe Face Landmarker（VIDEO モード）の顔のブレンドシェイプ（口角の上がり・下がり、眉の上がり・下がり、目の見開き、鼻のしわ 等）から、笑顔 / 驚き顔 / しかめ面 / 悲しい顔 / こわばり / 真顔 を 0..1 で出す。人によって普段の顔が違うので、その人の平常時の顔を基準に差分を見る（基準は自動で追従）。頭の動き（鼻先の速さを顔の幅で正規化）も取る。
4. **単語分割とカテゴリ推定**: ブラウザ内蔵の辞書 `Intl.Segmenter` で単語に分け、助詞・送り仮名を前の単語にくっつけて文節単位にする。各単語を `lexicon.js` の単語辞書と**漢字 1 文字ごとの意味**（例: 霊→恐怖、炎→パワー、桜→自然）で 恐怖 / 驚き / 喜び / 怒り / 悲しみ / 好き / パワー / ファンタジー / 食べ物 / 自然 / デジタル / おもしろ / 擬音 / カタカナ語 に分類する。辞書に無い単語でも漢字から推定できる。
5. **感情推定（声+表情）**: 単語のカテゴリ＋声と表情（`prosodyScores`）で 喜び / 驚き / 恐怖 / 怒り / 悲しみ / 平常 を選ぶ（例: 笑顔→喜び、しかめ面→怒り、口角が下がる→悲しみ、目を見開く→驚き）。強さは `computeIntensity` で声と表情・頭の動きを 1 つのスコアに統合（声が主で、表情は増幅役）。表情は会話の雰囲気（背景の色）にも少しずつ効き、真顔でしゃべり続けるとシリアス寄りになる。
6. **吹き出しの区切り**: 1 つの吹き出しに入れるのは、文の区切り（。！？）まで、または `CONFIG.paraMaxChars` 文字まで。超えたら続きを次の吹き出しに出す。
7. **文字起こし風の表示**: 単語を 1 文字ずつタイピングするように左から右へ打ち込み（`CONFIG.charStagger` 間隔）、画面の幅で行を折り返す。しゃべっている間は最後にカーソルが点滅する。新しい吹き出しは画面の下に出て、古い吹き出しは上へ押し出され、画面の上の方で薄くなって消える。一瞬で消えないので、見逃しても読み返せる。声が大きかった単語・内容のある単語ほど大きい（読める範囲に抑える）。
8. **内容に合わせた動き**: 単語のカテゴリから「ムード」（楽しい / 悲しい / 怖い / 怒り / 驚き / クール / 平常）を決め、登場の動きと、その後の動きを変える。内容の無い単語は、発話全体の感情のムードと色に合わせる。
   - 楽しい: 弾む・ポン・1 文字ずつジャンプ・回転・ぶら下がり・風船 → 登場後はぴょこぴょこ
   - 悲しい: ゆっくり降りる・しずくのように 1 文字ずつ落ちる・沈み込む → うなだれて沈む
   - 怖い: ノイズ・暗闇からじわじわ・点滅・震え → 小刻みに震える
   - 怒り: 叩きつけ・踏みつけ・横から突っ込む → 脈打つ
   - 驚き: ポン・弾ける・縦に開く → ときどき跳び上がる
   - クール: スライド・流れ込み・タイプライター・文字スクランブル → ほぼ静止
9. **見た目**: カテゴリでフォント・配色を選び、テレビのテロップ風に 影＋黒フチ＋白フチ＋グラデーション 等で描く。単語に合う絵文字（`lexicon.js` の `EMOJI`）があれば単語の後ろに添える。吹き出しは感情で輪郭が変わる（平常=角丸、驚き=ウニフラッシュ、怒り=ギザギザ、喜び=もこもこ、恐怖=波打つ、悲しみ=しずく）。集中線・紙吹雪は強く叫んだときだけ出す。
10. **白い背景の色の変化**: 背景は白がベース。話の内容（＋表情の積み重ね）で決まる会話の雰囲気の 3 色を薄く重ね、今の表情で 1 色目を表情の色に寄せる。声が大きいほど色が濃く広がり、声が高いほど色のかたまりが上へ昇る（低い声では下に沈む）。
11. **方言・若者言葉**: 関西弁・博多・広島・名古屋・東北・北海道・沖縄・土佐などの方言と若者言葉（ぴえん・エモい・それな 等）をカテゴリと絵文字の辞書に追加。方言の文末（やねん・ったい・じゃけえ・だがや・だべ・さー 等）は前の単語にくっつけ、強調語（めっちゃ・ばり・ぶち・でら・なまら・でーじ 等）は大きく表示する。
12. **どんな単語にも絵文字とカテゴリ**: 手書きの辞書（`lexicon.js` の `EMOJI`）と Unicode CLDR の日本語キーワード（`emoji-ja.js`、約 4000 語）の両方で単語を探し、長く一致した方の絵文字を付ける。さらに絵文字の分類（食べ物・動物・スポーツ・悲しい顔 等）から単語のカテゴリも推定するので、辞書に無い単語でも内容と雰囲気が分かる。Windows で表示できない新しい絵文字（Emoji 15 以降）は除外している。
13. **会話の雰囲気**: 確定した吹き出しの単語のムードと声から推定した感情を積み上げ（新しい吹き出しほど強く効き、時間とともに薄れる）、楽しい / ワクワク / 悲しい / シリアス / 怖い / 怒り / 平常 のうち最も強いものを背景の色に使う。
14. **今の話の要約**: 最近よく話に出た話題の絵文字を、画面の中央に大きく薄く出す（話題が変わるとクロスフェードで入れ替わる。顔など気分の絵文字は控えめに数える）。そのほかの話題は小さく右から左へ流れ（右＝今、左＝少し前）、よく出る話題ほど大きく残る。
15. **認識のヒント**: 新しい Chrome の「認識のヒント」（`SpeechRecognition.phrases`）が使える場合は、辞書の単語を渡して認識されやすくする。使えない環境では何もしない。

### 調整ポイント

- 反応の感度: `CONFIG.dbFloor` / `CONFIG.dbCeil`（会場のマイクに合わせて `D` キーの dB 値を見ながら調整）
- 文字の大きさ: `CONFIG.lineRatio`（基準の 1 文字の高さ）/ 単語ごとの大きさは `Chunk.weight`
- 字幕の位置・流れ方: `CONFIG.textBottom`（新しい吹き出しの下端）/ `CONFIG.fadeTop`（上で薄くなる範囲）/ `CONFIG.charStagger`（打ち込みの速さ）
- 1 つの吹き出しの長さ: `CONFIG.paraMaxChars`
- 語彙・フォント・配色・絵文字: `lexicon.js` の `WORDS` / `KANJI` / `CATEGORIES` / `EMOJI`（方言・若者言葉は `KANSAI` / `DIALECTS` / `SLANG` / `EXTRA_EMOJI`）。CLDR の表を作り直すときは `node tools/build-emoji-ja.js`
- ムードごとの動き: `script.js` の `MOOD_ENTRANCES` / `chunkEntrance` / `charEntrance` / `charIdle`
- 背景の色: `MOODS`（雰囲気ごとの 3 色）/ 声・表情の効き方は `drawBackground` 内
- 雰囲気・要約の移り変わり: `CONFIG.moodHalfLife` / `CONFIG.summaryHalfLife` / `CONFIG.summaryAlpha`
- 背景の話題: `CONFIG.topicLife`（消えるまで）/ `CONFIG.topicMax` / `CONFIG.topicAlpha`（濃さ）/ `CONFIG.topicDrift`（流れる速さ）
- 声と動きの混ぜ方: `computeIntensity` / `prosodyScores`
- 表情の感度: `CONFIG.faceGain`（大きいほど少しの表情でも反応）/ `CONFIG.faceMoodRate`（背景の色への効き方）/ 表情 → 感情の式は `updateFace` 内
